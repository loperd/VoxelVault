# 0.6.3

Production secrets are split by service: the API reads `secret/prod/voxel-vault`, the gateway reads `secret/prod/voxel-vault/gateway` into its own Secret (`secrets.vso.gatewayPath`, new VaultStaticSecret). Fill both KV paths before deploying (deploy/helm/voxel-vault/README.md).

Dropped the separate Identity callback credential: the API authenticates `/internal/*` with `GATEWAY_INTERNAL_TOKEN` again and the stock Overseer Gateway image is used (no patch, no local build). `IDENTITY_INTERNAL_TOKEN` is no longer read or required.
