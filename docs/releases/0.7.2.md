# 0.7.2

Neutral redesign of the frontend: new fonts (Geologica, Golos Text, OFL licenses in `licenses/`), shared tokens, light-grey buttons, a case scene without the ENDER CHEST caption, the «Кейсы» tab and a full-width open button on phones.

Block worlds read PBR maps (`<tile>_n`, `<tile>_s`) in the block shader. The miner vault gets a warm chest lamp and diffuse light shafts.

`deploy/bootstrap/vault-local.sh` seeds the Inventory and Wallet database URLs and no longer fails on `grep -q` under pipefail.

Error screens use the neutral light button fill (the red stays in the panel text and lines). The archive rarity filters share the case directory's tab style, the relic vault camera stands 9 blocks off like the other worlds, and the «Сундук не найден» page sits lower.

A full-screen notice appears the moment the connection drops: the browser's `offline` event shows it at once, and a failed request or a 5xx runs a check (two public hosts plus the API) that tells «no internet» from «server down», clears itself when the server answers, and offers a refresh button.

`docs/DESIGN.md` records the design system.
