# 0.7.3

The legacy economy is gone from the API. The case list and item images come from the rulebook, not from the old `chest_types` and `loot_items` tables. The one-off `economy-cutover` tool, its snapshot and its write fence are removed: API readiness only checks that the Inventory and Wallet opening baselines are complete and carry the same source and digest.

The API no longer connects to the old accounts database: `internal/store`, GORM and `DATABASE_URL` are removed from the API and the chart, and `runtime-grants` has no `accounts` context.

New one-off tool `/legacy-drop` (in the image): after a backup of the old accounts database, `DATABASE_URL=<operator connection> /legacy-drop -backup-taken` drops the retired `public` economy tables and the `legacy_economy_cutover` schema in one transaction. Run it only after 0.7.3 is deployed, since 0.7.2 still reads those tables. The tool is removed in the next release.

Block borders keep the main block's tone: 1px `var(--line)`, no accent stripes or tinted outlines.
