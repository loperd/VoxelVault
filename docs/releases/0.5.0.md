# 0.5.0

The economy runs on one engine. The legacy economy and the `ECONOMY_MODE` switch (legacy, contexts, maintenance) are removed; the API always serves the Wallet and Inventory contexts, so the wallet shows its transaction history to every player.

The API now starts only after the economy cutover is complete: the legacy source frozen, the Inventory and Wallet baselines imported and matching its snapshot. Without them the process exits and `helm --atomic` rolls the deployment back. Run the cutover (deploy/helm/voxel-vault/README.md, "Economy context activation") before deploying this release; during freeze and import the API is down.

`/api/v1/me` no longer returns `economyMode`. The HTTP contract in docs/reference/economy.md describes the context routes.
