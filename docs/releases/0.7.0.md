# 0.7.0

The economy configuration moves from files into the database, and accounts are opened only by an explicit seed.

## Config in the database

`economy.json` (rulebook), `transfers.json` and `security.json` are now versioned revisions in the Inventory, Ledger and Security databases (`rulebook_revisions`, `transfer_config_revisions`, `policy_revisions`, each with an `*_active` pointer, shared code in `platform/configrevision`). Services read the active revision at start. The files stay only as seed input and test fixtures; `ECONOMY_CONFIG`, `TRANSFER_CONFIG` and `SECURITY_POLICY_FILE` are removed. Runtime roles get `SELECT` on the new tables (run `runtime-grants`).

New binaries: `/economy-seed` (loads the rulebook and transfer config) and `/security-migrate` (Security schema and policy seed).

## Accounts

Code no longer opens accounts implicitly. `Store.OpenAccount` is the only way to open a treasury account; postings to an unopened account fail with `ErrAccountNotOpen`. `transfers.json` lists the accounts to open: `platform-tax`, `treasury`, `inventory-buyback`. `AccountService` is removed.

## Treasury

The treasury buys at 0.6–0.75 of the price (sell rate 2.5 → 0.7, so prices drop about 3x). The 1% transfer tax goes to `platform-tax`; the new `tax-sweep` job (Helm CronJob, hourly at :05) moves it to `treasury`.

## Admin requests

The treasury moves to the buyback account only through a signed request: three distinct parties sign with Ed25519 keys via the new `ledgerctl`, the API serves `/internal/ledger-admin/` (keep it off the public ingress), every step is in a hash-chained audit. Ledger migration 9; `economy-seed` takes `ADMIN_KEYS` to register the public keys. See `docs/reference/economy.md`.

## Removed

The one-off Identity and Security migration job and the ledger ownership upgrade script `deploy/upgrade-ledger.py`; the legacy inventory and wallet models.

## Deploy order

`/wallet-migrate`, `/inventory-migrate`, `/security-migrate`, `/economy-seed` (with `ADMIN_KEYS`), `/runtime-grants` for every context, then the new API.

## Earlier in this release

Two Ledger transfer races fixed: a restriction committed while a confirmation is in flight is honoured (`clock_timestamp()` instead of `now()`), and the per-minute transfer cap holds across currencies (subject-wide advisory lock).
