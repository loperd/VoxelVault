# 0.6.0

Wallet transfers between players with account restrictions. Send and receive blocks (operator CLI `account-restrict`, automatic time-limited block on a transfer burst) are checked at quote and confirmation. Restriction changes publish `restriction.added|lifted|expired` events through the new generic outbox (`platform/outbox`, topic `account-restrictions`); a CronJob (`restrictionExpiry` in Helm values) publishes expirations. Nothing is deleted from the database.

The ledger requires Goose version 7: migration 7 renames schema `wallet` to `ledger` and adds transfers, restrictions and the outbox `kind` column. Stop API and workshop-worker writers before migrating (deploy/helm/voxel-vault/README.md).
