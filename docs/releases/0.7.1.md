# 0.7.1

Ledger admin requests no longer have an HTTP endpoint: the API stops serving `/internal/ledger-admin/` (the `ledgeradmin` package is gone). `ledgerctl` now talks to the Ledger database directly (`WALLET_DATABASE_URL`) and runs as a console command inside an API pod; it ships in the API image. Signing, the three-party rule and the hash-chained audit are unchanged. See `docs/reference/economy.md`.

Gateway moves to v0.1.22, which reads `GATEWAY_UPSTREAM_URL`, `GATEWAY_SESSION_SECRET` and `GATEWAY_INTERNAL_TOKEN` instead of the `LONCHA_*` names; the chart sets the new names (the Secret keys are unchanged). The frontend deploy uses wrangler 4.155.0 (4.20.0 failed against the Cloudflare assets API).
