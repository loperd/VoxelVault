# 0.6.4

Two Ledger transfer races fixed (found by the security audit, reproduced on a throwaway PostgreSQL).

An account restriction committed while a transfer confirmation was already in flight is now honoured: the restriction predicate compares `created_at` with `clock_timestamp()` instead of the older transaction's `now()`.

The per-minute transfer cap now holds across currencies: confirmations of one subject take a subject-wide advisory lock before the count, so two currencies can no longer both pass at nine of ten. No schema change.
